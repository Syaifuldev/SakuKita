# 📒 SakuKita

**Catat. Atur. Tumbuh.**

Aplikasi web catatan keuangan pribadi yang mobile-friendly. Dibangun dengan HTML, CSS, dan JavaScript murni.

## ✨ Fitur

- 🔐 Login & Register (username + password)
- 📊 Dashboard dengan ringkasan saldo, pemasukan & pengeluaran
- ➕ Tambah, edit, hapus catatan keuangan
- 📒 Laporan bulanan dengan filter
- 📄 Export laporan ke PDF
- 📱 Mobile-first design (Bottom Navigation)
- 💾 Data tersimpan di LocalStorage

## 🚀 Cara Menjalankan

Buka `index.html` di browser, atau gunakan server lokal:

```bash
npx -y serve
```

## 🛠️ Teknologi

- HTML5
- CSS3 (Vanilla, Custom Properties)
- JavaScript (ES6+)
- Google Fonts (Plus Jakarta Sans)
